### Week I - Title Selection

* Identified the relevance of digital tools in preserving traditional medicinal plant knowledge.
* Selected the project title "*Virtual Herbal Garden*" aligning with AYUSH and SIH2024 goals.
* Outlined project vision to provide a multilingual, interactive, and educational platform for medicinal plant knowledge.

### Week II - Problem Statement and Justification

* Defined the problem of limited digital awareness and accessibility regarding India's rich heritage of medicinal plants.
* Justified solution by supporting education, conservation, and application of traditional medicine.
* Proposed solution includes features like search-by-ailment, plant cards, AR viewing, and community learning.

### Week III - Requirement Analysis

* Finalized platform functionalities:

  * Interactive plant database
  * Symptom-based search
  * Augmented Reality (AR) visualization
  * Educational quizzes
  * Multi-language support
* Identified target user base: students, researchers, farmers, and general public.

### Week IV.1 - Technology Research and Design Planning

* Chose technology stack:

  * Backend: Python (Flask)
  * Frontend: ReactJS, AR.js for WebAR integration
  * Mobile: React Native
  * Database: MySQL
* Designed user journey, UI wireframes, and database schema.
* Focused on UX accessibility and localization (regional languages).

### Week IV.2 - Data Collection and Categorization

* Collected structured data of 150+ medicinal plants from AYUSH, NMPB, and WHO databases.
* Categorized data by:

  * Botanical name
  * Common name
  * Medicinal uses
  * Ailments treated
  * Parts used and region of origin
* Cleaned and verified data with reliable sources.

### Week IV.3 - Backend and Database Setup

* Designed relational schema with entities like Plants, Ailments, LanguageContent.
* Implemented APIs for:

  * Search
  * Filter
  * Quiz generation
  * AR model fetch
* Connected backend with MySQL database.

### Week V.1 - Frontend and Interface Design

* Developed ReactJS frontend:

  * Homepage with search functionality
  * Categorized plant display
  * Individual plant detail pages
* Initiated UI design for the mobile app (basic screens).

### Week V.2 - Module Development – Plant Explorer, Search & Filter

* Built searchable, filterable Plant Explorer component.
* Implemented symptom-based search logic using keyword-AI mapping.
* Enabled multilingual toggle for plant descriptions and uses.

### Week VI - Module Development – AR/VR Integration, Quiz, and Info Cards

* Integrated AR view using WebAR for selected plants (3D model + usage overlay).
* Created dynamic plant info cards showing images, scientific data, and usage tips.
* Developed interactive quiz module for herbal knowledge testing.

### Week VII - Integration and System Testing

* Merged backend, frontend, and AR modules into one platform.
* Conducted:

  * Functional and usability testing
  * Localization checks for Marathi, Hindi, and English
  * AR performance and mobile compatibility testing
* Resolved interface and data rendering issues.

### Week VIII - Project Presentation II

* Demonstrated platform with all features including AR demo, search-by-ailment, and quizzes.
* Highlighted potential community use and integration with AYUSH digital libraries.
* Gathered mentor feedback and improved accessibility and layout.

### Week IX - Documentation and Report Writing

* Created complete technical documentation including:

  * System architecture and diagrams
  * Plant database structure
  * Module explanations with screenshots
  * Testing reports
* Compiled user guide and admin operation manual.

### Week X - Conclusion and Future Scope

* Concluded that *Virtual Herbal Garden* is a step towards digital conservation of India’s traditional medicine.
* Proposed future features:

  * AI chatbot for health queries
  * Community submission of plants
  * Offline mobile version
  * Integration with e-commerce for herbal products

### Week XI - Final Project Report Submission

* Finalized and submitted:

  * Source code on GitHub
  * Project documentation and manuals
  * Demo video with narrated walkthrough
  * Submission on SIH 2024 portal

# 📜 Conclusion

The *Virtual Herbal Garden* provides a user-friendly, accessible, and visually interactive gateway to India’s vast heritage of medicinal plants. By leveraging AI, multilingual content, and AR technology, the platform fosters public awareness, education, and preservation of traditional knowledge, aligning with the objectives of the AYUSH Ministry and national digital initiatives.
